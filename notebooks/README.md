# Pilot C notebooks (run on Kaggle)

Generated by `notebooks/build_notebooks.py`; do not edit the `.ipynb` files by hand. Naming rule (DECISIONS.md on `paper/main`): `<pilot letter><number>_<what>__<accelerator>.ipynb`, flat in `notebooks/`. Kaggle uses the file name as the title.

> **Note:** The **GPU L4 x4** option only appears after the competition `gemma-4-developer-agent` is attached as an input.

> **Environment:** These notebooks must run in the **official starter's pinned Kaggle environment (Python 3.12)**. New Kaggle notebooks default to Python 3.13, and pip then rejects the wheelhouse's cp312 wheels. Every notebook's first code cell stops it within seconds on any other Python version.

## How to run any of these notebooks (same steps for each; accelerator and inputs per the table)

1. Open the official starter: https://www.kaggle.com/code/ryanholbrook/getting-started-gemma-4-developer-agent and click **Copy & Edit**. The copy keeps the starter's pinned environment (Python 3.12) and its inputs: the competition, the wheelhouse and the four Gemma 4 models.
2. In the copy: **File → Import Notebook** → upload the notebook's `.ipynb` from branch `pilot/c-bottleneck`. This replaces the cells; the environment and inputs stay.
3. Rename the notebook (title, top left) to the file name without `.ipynb`.
4. Right panel → **Settings**: Environment = **Pin to original environment** (do not switch to "Always use latest environment"); Accelerator = as in the table; Internet = **Off**.
5. Inputs: Attach the earlier notebook's output listed in the table (Add input → Your Work → Notebooks). CPU notebooks don't need the Gemma 4 models that came with the copy (you can remove them).
6. **Save Version → Save & Run All**. The first code cell prints the Python version and stops within seconds if it is not 3.12. In that case the environment is not the starter's: redo steps 1–4.

> **Freeze protection (GPU notebooks):** every request to the inference server has a timeout, and a watchdog polls its `/health`. If the server stops responding (~90 s), the watchdog kills it, the next unit of work gets a fresh server, and the session stops after a second freeze. Freezes are listed under `freezes` in the output file.

CPU notebooks (`C00`, `C03v`) install only the 5 wheelhouse wheels they need: `swegemma`, `adk_eval_core`, `adk_submission`, `google_adk`, `google_genai` (all pure Python). GPU notebooks install the starter's full set of 41.
