# LEARNINGS — verified findings that affect more than one pilot

One dated line per finding, with its source. Append only. **Always `git pull` before editing; if a push
is rejected, pull and retry.** Mark anything not verified in the real runtime as such.

- 2026-10-31 · The local swegemma `Evaluator` verifies EMPTY patches, the scorer does not (empty prediction = `NO_PATCH`, unresolved). Count a task as resolved only if the patch is non-empty, or local solve rates are inflated. Source: swegemma 0.2.11 `evaluate.py` + HARNESS_README §8.2; papermill dry run of pilot C notebook 01 (requests_7309 "resolved" with no patch). (pilot C)
- 2026-10-31 · Some dev tasks pass their required tests with NO patch in the subprocess sandbox (locally: requests_7309, requests_7427, requests_7315; all three locally gold-passing requests tasks). A task is valid only if the gold patch passes AND the no-patch run fails. Notebook 00 now checks both. Source: pilot C notebook 00 papermill dry run. (pilot C)
- 2026-10-31 · Token-threshold compaction (last prompt ≥ 14,336 tokens) runs before model calls, i.e. mid-turn, and its event is appended to the session but never yielded, so it is ABSENT from harness traces. Trace-based compaction counts read 0 (mock run: 0 in trace vs 15 seen by the summarizer probe). Source: google-adk 1.36.1 `flows/llm_flows/compaction.py`, `runners.py`; `common/runtime_probes.py` in a papermill dry run of 01. Real-model frequency: pending notebook 01. (pilot C)
- 2026-10-31 · The compaction summarizer formats only `part.text`, so tool calls and responses (including `load_skill` output) are dropped. It compacts all events except the last 5, INCLUDING the initial task prompt (problem statement + any hints). After the first compaction, 0 of 21 requests still contained "Problem Statement:" (mock run). Confirms and extends pilot A's finding. Source: `apps/llm_event_summarizer.py`, `apps/compaction.py`; dry run. (pilot C)
- 2026-10-31 · `AgentTool` sub-agents (e.g. `code_analyzer_agent`) run in a separate ADK Runner, so their tool calls are not in the root trace; only the AgentTool call is. Source: google-adk `tools/agent_tool.py`. (pilot A first; confirmed by pilot C)
- 2026-10-31 · The sandbox venv inherits the host's site-packages (`system_site_packages=True`), so whether a gold patch passes depends on the host image. Local: 73/129 gold pass. Causes seen: `dirty_equals` missing (fastapi), `pytest-httpbin` fixture missing (requests), pygments-dependent ANSI output (rich). Forum (J. Wold): 27 fastapi tasks fail on missing `inline_snapshot`/`dirty_equals`; notebook 00 checks this on Kaggle. Source: swegemma `sandbox/subprocess.py`; `results/gold_check_local_summary.json`. (pilot C)
- 2026-10-31 · Kaggle runs notebooks with papermill and stops at the first error: a `%%writefile` cell with an empty body raises `UsageError`. Never emit empty writefile cells; dry-run every notebook with papermill. Source: notebook 00 failure on Kaggle (user report). (pilot C)
- 2026-10-31 · Chat templates differ by size: e2b = e4b ≠ 12b ≠ 31b (md5); the 31B template adds an empty thought block when thinking is off. Any prompt construction or likelihood scoring must use each size's own template. The tokenizer.json is the same size for all four (not byte-compared). Source: Kaggle model files `chat_template.jinja`. (pilot C)
- 2026-10-31 · The harness graph tools run offline without a sandbox: `SwegemmaContext(docker_manager=None, ..., graph_dir, embeddings_dir).create_tools()` returns a dict of callables; `get_code_neighbors` returns `{"status","node","neighbors":["<repo>;<id>",...],"count","is_truncated"}` and includes test nodes. Source: local test with swegemma 0.2.11. (pilot C; relevant to pilot B)
- 2026-10-31 · 21/129 dev tasks have hidden tests that require a new name or exact message absent from the issue text (heuristic, `pilot_c/info_checks.py`). Such information can't be found by search, and test-name hints leak it. Source: `results/info_spec_dev129.json`. (pilot C)
- 2026-10-31 · The scorer's required tests = the `def test_*` added in `test_patch` (`_extract_test_functions_from_patch`); `common/diffs.py:required_test_names` equals it on 129/129 tasks. Source: `pilot_c/check_test_names.py`. (pilot C)
